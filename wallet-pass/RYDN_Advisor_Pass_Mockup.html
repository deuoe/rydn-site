Design notes

  • Front: brand-color gradient (3 variants shown — pick one, or let advisors pick), advisor photo, name in Fraunces (your display font), specializations as glassmorphic chips. Top-right has a faux "credit card chip" + RYDN orbit logo for premium feel.
  • Back: White card with all advisor metadata + a real QR code (generated per advisor — links to their /advisors/:slug page).
  • Sizing: Designed to match Apple Wallet's actual pass dimensions (~330x440pt).
  • Photo: Mockup uses initials avatars. Real passes will embed actual advisor photos via Apple PassKit's strip image slot.
  • QR code: Decorative in mockup. Real implementation generates a unique QR per advisor pointing to their RYDN profile.

Three implementation paths

  • Easy: PassKit.com (free up to 100 passes). Drag-and-drop editor, both Apple + Google Wallet. ~30 min total setup.
  • Medium: Use Apple's PassKit API directly. Need Pass Type ID certificate (free with your Apple Dev account) + a static pass generator. ~3-4 hours setup, then one-click to add advisors.
  • Hard: Build a full server that generates + signs passes on demand, with revocation API. Overkill for 14 advisors.
